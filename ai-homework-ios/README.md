# AI Homework — решатель школьных заданий для iPhone

Приложение в духе Galaxy AI / Circle to Search для iOS: нажмите кнопку действия или сфотографируйте
задание, обведите нужную часть пальцем — и получите ответ, объяснение и пошаговое решение.

Без нейросети по API типовые задачи (уравнения, неравенства, физика «в одну формулу», химия, системы
счисления) решаются точными алгоритмами **прямо на iPhone**, без сети. Если подключена **нейросеть по вашему
API-ключу** (apimira, OpenRouter, OpenAI, Anthropic и любой совместимый сервис), текст **каждого** задания
уходит на указанный вами адрес: нейросеть-диспетчер решает, кому его отдать, — точному решателю на iPhone
или ей самой. Изображение уходит в нейросеть только если включить «Отправлять изображение в нейросеть»
(по умолчанию выключено). Без интернета работает Apple Intelligence, если она поддерживает язык.
Без регистрации и аналитики.

## Возможности

| Что | Как реализовано |
|---|---|
| Камера, галерея, буфер обмена, сканер документов, ввод текстом | `UIImagePickerController`, `PhotosPicker`, `UIPasteboard`, VisionKit `VNDocumentCameraViewController` |
| Выделение части задания («обведи, чтобы решить») | `RegionSelectionView` — лассо + маркеры углов |
| Распознавание текста (русский, английский, формулы) | Apple Vision `VNRecognizeTextRequest`; второй проход без автозамены для формул |
| Определение предмета | словари основ слов + структурные признаки (формулы, единицы, химические формулы) |
| Математика | собственный движок: точные рациональные числа, уравнения (линейные, квадратные, высших степеней, дробные, с модулем, тригонометрические), неравенства (метод интервалов), системы, упрощение, разложение на множители, производные, интегралы, проценты, НОД/НОК |
| Физика | задачи «в одну формулу» (26 формул), перевод единиц в СИ, табличные константы |
| Химия | 118 элементов, молярная масса, массовые доли, количество вещества, уравнивание реакций |
| Информатика | системы счисления 2–16, единицы информации |
| Русский, английский, литература | орфография (`UITextChecker`), части речи и леммы (NaturalLanguage), имена и места, системный перевод и словарь |
| Текстовые и сложные задания | нейросеть по API пользователя (форматы OpenAI и Anthropic; выделенный фрагмент уходит картинкой, только если это включено в настройках); без интернета — Apple Intelligence (iOS 26+, если поддерживает язык) |
| История и избранное | SwiftData, поиск, фильтры, группировка по дням |
| Экспорт | PDF (A4, несколько страниц) и стандартное меню «Поделиться» |
| **Кнопка действия** | команда «Сделать снимок экрана → Решить скриншот» (скриншот + выделение области); элементы управления iOS 18 для камеры и сканера |
| Дизайн | Liquid Glass на iOS 26 (`glassEffect`), материалы на iOS 17–18, MeshGradient, spring-анимации, `matchedGeometryEffect`, haptics, светлая и тёмная темы |

### Честность ответов

Приложение **не имитирует** нейросеть заготовленными ответами. Каждое решение помечено:

* **Точное решение** — вычислено алгоритмом и проверено подстановкой;
* **Приближённо** — часть значений найдена численно;
* **Проверьте «Дано»** — вычисление точное, но условие задачи понято автоматически (в том числе когда его
  переписала нейросеть-диспетчер: запись показывается первой пометкой);
* **Сгенерировано моделью** — ответ нейросети (по API или Apple Intelligence), может содержать ошибки;
* **Не решено** — с объяснением причины и тем, что можно сделать.

## Установка на iPhone без Mac — через SideStore

Приложение собирается в облаке GitHub (там есть macOS и Xcode) и публикуется в релизе
[`ai-homework-latest`](https://github.com/doppelrose/claude-code-best-practice/releases/tag/ai-homework-latest).
На телефон оно ставится через **SideStore**: компьютер нужен **один раз**, а дальше SideStore
сам продлевает 7-дневную подпись бесплатного Apple ID прямо на iPhone.

Что понадобится: iPhone с **iOS 17+** и код-паролем, бесплатный Apple ID, Wi-Fi и на один раз —
компьютер на Windows 10/11 (64-бит), Linux или macOS с кабелем USB.

### 1. Подготовка iPhone

1. Установите из App Store бесплатное приложение **LocalDevVPN**.
2. Откройте его и нажмите **Connect**; на вопрос «Разрешить конфигурации VPN» ответьте «Разрешить».
   Этот VPN работает только внутри телефона (никуда не передаёт трафик) — через него SideStore
   устанавливает и продлевает приложения. Он должен быть включён, когда SideStore что-то ставит или продлевает.

### 2. Установка SideStore (один раз, с компьютера)

1. Windows: установите **iTunes** с сайта Apple (если не заработает — приложение «Устройства Apple» из Microsoft Store).
2. Скачайте и установите **iloader** со страницы релизов github.com/nab138/iloader (для Windows — файл `iloader-windows-x64.msi`).
3. Подключите iPhone кабелем, разблокируйте, нажмите «Доверять этому компьютеру».
4. В iloader войдите в свой Apple ID, выберите iPhone и нажмите **Install SideStore (Stable)**.
5. На iPhone: **Настройки → Основные → VPN и управление устройством** → ваш Apple ID → **Доверять**.
6. **Настройки → Конфиденциальность и безопасность → Режим разработчика** → включить (iPhone перезагрузится).
7. Включите LocalDevVPN (**Connect**), откройте **SideStore**, войдите в тот же Apple ID.
8. Вкладка **My Apps** → нажмите на счётчик **7 DAYS** рядом с SideStore, чтобы завершить настройку
   (на вопрос о сертификате ответьте «Yes» / «Refresh Now»).

Компьютер больше не нужен.

### 3. Установка AI Homework (на iPhone)

Приложение собирается в облаке **Codemagic** (codemagic.io, бесплатно, вход через GitHub) по файлу
`codemagic.yaml` в корне репозитория.

1. В Codemagic откройте последнюю сборку **AI Homework — iPhone .ipa** → блок **Artifacts** →
   нажмите **AIHomework.ipa** и сохраните файл в «Файлы» (удобнее всего из Safari).
2. Включите LocalDevVPN (**Connect**).
3. SideStore → **My Apps** → **+** → выберите `AIHomework.ipa` из «Файлов».
4. Готово: иконка AI Homework появится на экране «Домой».

Новая версия: запустите сборку в Codemagic (**Start new build**, ветка `main`) и повторите шаги 1–3.
SideStore установит её поверх старой, история заданий сохранится.

Если на GitHub Actions доступен macOS-раннер, тот же `.ipa` публикуется в релизе `ai-homework-latest`
вместе с источником SideStore (`…/releases/download/ai-homework-latest/source.json`) — тогда
обновления приходят прямо в SideStore.

### Как продлевается подпись

* SideStore **сам продлевает** приложения в фоне, пока включён LocalDevVPN и телефон в Wi-Fi.
* Вручную: SideStore → **My Apps** → нажать на счётчик дней рядом с приложением.
* Счётчик показывает, сколько дней осталось; если он дошёл до нуля, приложение перестанет
  открываться до продления — данные при этом не пропадают.
* Новые версии из CI приходят как обновления в SideStore (вкладка **My Apps / Updates**).

### Ограничения бесплатного Apple ID в SideStore

* Не больше **3 приложений** одновременно (включая сам SideStore) — AI Homework занимает одно место.
* Не больше **10 App ID в неделю**: AI Homework использует 2 (приложение + расширение «Элементы управления»).
* Если iOS обновили или сбросили, файл сопряжения SideStore может устареть — тогда его один раз
  обновляют через iloader («pairing file»).

### Если всё-таки есть Mac

Откройте `AIHomework.xcodeproj` в Xcode 16+ (лучше Xcode 26), в **Signing & Capabilities** выберите
свою команду для целей **AIHomework** и **AIHomeworkControls**, задайте уникальные Bundle Identifier
(расширение — с префиксом приложения, например `com.<имя>.aihomework.controls`) и нажмите **Run**.

## Кнопка действия (Action Button)

Нажатие кнопки делает скриншот текущего экрана и открывает AI Homework: вы обводите задание
пальцем — и решение начинается сразу. iOS не разрешает приложениям снимать экран других приложений,
поэтому скриншот делает приложение «Команды». Настройка один раз:

1. «Команды» → **+**.
2. Добавьте действие **«Сделать снимок экрана»**.
3. Добавьте действие **«Решить скриншот»** (AI Homework); в поле «Изображение» должен стоять «Снимок экрана».
4. Назовите команду, например «Решить с экрана».
5. **Настройки → Кнопка действия → Команда** → выберите эту команду.

Другие варианты: **Элемент управления** (iOS 18) → AI Homework → «Решить задание» (камера) или
«Сканировать задание»; действие «Решить задание» в «Командах» с параметром «Способ ввода».

Как это устроено: `AIHomework/App/ScreenshotIntent.swift` — интент с параметром-изображением
и `openAppWhenRun`; он сохраняет скриншот во временный файл, а `AppModel.handlePendingQuickAction()`
открывает его в режиме выделения. Окончание обводки (`RegionSelectionView.onSelectionFinished`)
сразу запускает распознавание и решение.

## Нейросеть по API

**Настройки → Нейросеть по API**:

| Поле | Что вписать |
|---|---|
| Формат API | **OpenAI** (`/chat/completions`) — apimira, OpenRouter, OpenAI, DeepSeek, Gemini и большинство агрегаторов; **Anthropic** (`/messages`) — Anthropic и совместимые сервисы |
| Адрес API | из личного кабинета сервиса, обычно заканчивается на `/v1` (только `https://`) |
| Ключ API | ключ сервиса; хранится в Связке ключей iPhone (`KeychainStore`), в `UserDefaults` и историю не попадает |
| Модель | название модели в сервисе; кнопка «Проверить и загрузить модели» подтянет список через `GET /models` |

Кнопка «Отправить тестовый вопрос» проверяет, что модель отвечает. Ключ привязан к адресу, для которого
его ввели: если адрес изменился, ключ туда не отправляется, пока вы не введёте его заново или явно не
подтвердите новый адрес. Запросы идут через отдельную сессию без кэша и cookies; редирект на другой хост
запрещён.

**Изображение.** По умолчанию в API уходит только распознанный текст. Переключатель **«Отправлять
изображение в нейросеть»** разрешает отправлять выделенный фрагмент (JPEG до 1600 px) — только в запрос
полного решения, диспетчеру никогда. Для этого выбирайте модель, которая понимает изображения (vision);
если модель картинку не принимает, задание повторяется только с текстом. Если Vision не нашёл на фрагменте
текста (чертёж, рукопись), а отправка изображения выключена, приложение предложит включить её или ввести
условие вручную.

Порядок решения (`SolveCoordinator`), когда настроен API:

1. **Нейросеть-диспетчер** (`Engine/Core/TaskRouting.swift`) получает распознанный текст (без изображения)
   и отвечает одной строкой JSON: `local` — задание по силам точному решателю, или `model` — нужно
   полноценное решение. Для `local` она переписывает условие в понятной решателю записи
   (`x^2 - 5x + 6 = 0`, «Автомобиль проехал 150 км за 2 ч…») и попутно исправляет ошибки OCR.
   Текст задания передаётся в границах `<task>…</task>` как данные: команды внутри него модель выполнять не должна.
2. `local` → точный решатель на iPhone; если запись отличается от распознанного текста, ответ помечается
   «Проверьте „Дано“» с записью нейросети. Если решатель не справился — задание уходит в API.
3. `model` → полноценное решение нейросетью по API.

Если диспетчер ответил непонятно, пусто, ошибкой 400 или не успел, задание решается как обычно (в том числе
по API). API отключается на это решение только при сетевой ошибке или ошибке ключа, адреса, баланса.
В истории и PDF сохраняются только код ошибки и пояснение приложения, без текста ответа сервера.

Без API или без интернета: точные алгоритмы → Apple Intelligence → честное сообщение об ограничении.
У каждого шага есть лимит времени (диспетчер 25 с, точный решатель 6 с, решение по API 75 с,
Apple Intelligence 60 с — `Engine/Core/Deadline.swift`), поэтому решение не может зависнуть.
Сетевой код — `Services/RemoteAPIProvider.swift`; формирование запросов и разбор ответов обоих
форматов — `Engine/Core/RemoteAPI.swift` (покрыто тестами).

### Apple Intelligence без интернета

На iOS 26 и устройствах с Apple Intelligence (iPhone 15 Pro и новее) приложение использует системную
модель через фреймворк Foundation Models, когда нейросеть по API недоступна. Она получает только
распознанный текст (не изображение). Если модель не поддерживает язык приложения (на момент написания —
русский), приложение её не вызывает и честно сообщает об этом. Статус показан в **Настройки → Без интернета**.

## Архитектура

```
AIHomework/
├── App/            точка входа, AppModel (навигация, источники ввода, быстрые действия), настройки
├── DesignSystem/   стекло, кнопки, фон, орб, общие компоненты
├── Features/       Home, Capture, Solve (MVVM: SolveViewModel + экраны), History, Subjects, Settings
├── Services/       OCR (Vision), анализ текста, нейросеть по API, Apple Intelligence, Связка ключей, PDF, координатор
├── Persistence/    SwiftData-модель истории
└── Engine/         движок решения без UI: Math, Physics, Chemistry, Text, Core
Shared/             App Intent «Решить задание» (приложение + расширение)
AIHomeworkControls/ элементы управления iOS 18 для Пункта управления и кнопки действия
EngineTests/        тесты движка
```

Движок (`AIHomework/Engine`) не зависит от UIKit и собирается отдельно как Swift-пакет,
поэтому его можно тестировать даже на Linux:

```bash
cd ai-homework-ios
swift test        # 57 тестов: математика, физика, химия, информатика, предметы, запросы к API, маршрутизация, лимиты времени
```

CI (`.github/workflows/ai-homework-ios.yml`) прогоняет тесты движка и собирает установочный
файл `AIHomework.ipa` для iPhone на облачном macOS-раннере.

## Ограничения

* Физика — задачи в одно действие; многошаговые задачи требуют языковой модели.
* Рукописный текст Vision распознаёт хуже печатного — проверяйте распознанное условие (его можно исправить перед решением).
* Задачи на геометрию с чертежами не распознаются как чертежи — только текст условия.
* Ответы языковых моделей помечаются как сгенерированные и могут содержать ошибки.
