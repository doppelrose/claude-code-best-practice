# AI Homework — решатель школьных заданий для iPhone

Приложение в духе Galaxy AI / Circle to Search для iOS: сфотографируйте задание, обведите
нужную часть пальцем — и получите ответ, объяснение и пошаговое решение.
**Всё работает на устройстве: без API-ключей, регистрации, серверов и аналитики.**

## Возможности

| Что | Как реализовано |
|---|---|
| Камера, галерея, буфер обмена, сканер документов, ввод текстом | `UIImagePickerController`, `PhotosPicker`, `UIPasteboard`, VisionKit `VNDocumentCameraViewController` |
| Выделение части задания («обведи, чтобы решить») | `RegionSelectionView` — лассо + маркеры углов |
| Распознавание текста (русский, английский, формулы) | Apple Vision `VNRecognizeTextRequest`; второй проход без автозамены для формул |
| Определение предмета | словари основ слов + структурные признаки (формулы, единицы, химические формулы); опционально — классификатор Core ML |
| Математика | собственный движок: точные рациональные числа, уравнения (линейные, квадратные, высших степеней, дробные, с модулем, тригонометрические), неравенства (метод интервалов), системы, упрощение, разложение на множители, производные, интегралы, проценты, НОД/НОК |
| Физика | задачи «в одну формулу» (26 формул), перевод единиц в СИ, табличные константы |
| Химия | 118 элементов, молярная масса, массовые доли, количество вещества, уравнивание реакций |
| Информатика | системы счисления 2–16, единицы информации |
| Русский, английский, литература | орфография (`UITextChecker`), части речи и леммы (NaturalLanguage), имена и места, системный перевод и словарь |
| Текстовые предметы (история, обществознание…) | локальная языковая модель: Apple Intelligence (iOS 26+) или своя модель Core ML |
| История и избранное | SwiftData, поиск, фильтры, группировка по дням |
| Экспорт | PDF (A4, несколько страниц) и стандартное меню «Поделиться» |
| **Кнопка действия** | App Intent + App Shortcuts (iOS 17) и элементы управления (iOS 18+) |
| Дизайн | Liquid Glass на iOS 26 (`glassEffect`), материалы на iOS 17–18, MeshGradient, spring-анимации, `matchedGeometryEffect`, haptics, светлая и тёмная темы |

### Честность ответов

Приложение **не имитирует** нейросеть заготовленными ответами. Каждое решение помечено:

* **Точное решение** — вычислено алгоритмом и проверено подстановкой;
* **Приближённо** — часть значений найдена численно;
* **Проверьте «Дано»** — вычисление точное, но условие задачи понято автоматически;
* **Сгенерировано моделью** — текст локальной языковой модели, может содержать ошибки;
* **Не решено** — с объяснением причины и тем, что можно сделать.

## Установка на iPhone без Mac

Приложение собирается в облаке GitHub (там есть macOS и Xcode), а на телефон ставится
с обычного компьютера на **Windows**. Mac и Xcode не нужны.

Что понадобится: iPhone с **iOS 17+**, кабель USB, компьютер на Windows 10/11 и бесплатный Apple ID.

### 1. Скачайте готовый файл AIHomework.ipa

1. Откройте репозиторий на GitHub → вкладка **Actions** → workflow **AI Homework iOS**.
2. Выберите последний зелёный запуск (✓) — внизу страницы, в блоке **Artifacts**, скачайте `AIHomework-ipa`.
3. Распакуйте zip — внутри файл `AIHomework.ipa`.

Чтобы собрать заново вручную: **Actions → AI Homework iOS → Run workflow**.

### 2. Установите Sideloadly на Windows

1. Установите **iTunes** и **iCloud** с сайта Apple (версии *не* из Microsoft Store) — они нужны Windows, чтобы «видеть» iPhone.
2. Скачайте и установите **Sideloadly** с сайта sideloadly.io.

### 3. Поставьте приложение на iPhone

1. Подключите iPhone кабелем, разблокируйте его и нажмите «Доверять этому компьютеру».
2. Запустите Sideloadly, перетащите в окно `AIHomework.ipa`.
3. В поле **Apple account** введите свой Apple ID и нажмите **Start**. Sideloadly подпишет приложение вашим Apple ID (пароль уходит только в Apple).
4. На iPhone: **Настройки → Конфиденциальность и безопасность → Режим разработчика** → включить (телефон перезагрузится).
5. **Настройки → Основные → VPN и управление устройством** → ваш Apple ID → **Доверять**.
6. Откройте AI Homework.

> С бесплатным Apple ID подпись действует **7 дней** — потом повторите шаг 3 (данные приложения сохранятся).
> В Sideloadly можно включить автоматическое продление, пока компьютер и iPhone в одной сети Wi-Fi.
> Альтернатива Sideloadly — **AltStore** (altstore.io), он тоже работает на Windows.
>
> Если Sideloadly выдаёт ошибку подписи расширения, включите в **Advanced options → Remove app extensions**.
> Приложение будет работать полностью, пропадут только «Элементы управления» iOS 18 —
> кнопку действия тогда настройте через «Команду» (см. ниже), она входит в само приложение.

### Если всё-таки есть Mac

Откройте `AIHomework.xcodeproj` в Xcode 16+ (лучше Xcode 26), в **Signing & Capabilities** выберите
свою команду для целей **AIHomework** и **AIHomeworkControls**, задайте уникальные Bundle Identifier
(расширение — с префиксом приложения, например `com.<имя>.aihomework.controls`) и нажмите **Run**.

## Кнопка действия (Action Button)

На iPhone 15 Pro, iPhone 16 и новее задание можно открыть одним нажатием:

* **iOS 18 и новее:** Настройки → Кнопка действия → **Элемент управления** → AI Homework →
  «Решить задание» (камера) или «Сканировать задание» (сканер документов).
* **iOS 17:** Настройки → Кнопка действия → **Команда** → AI Homework → «Решить задание».

В приложении «Команды» действие «Решить задание» имеет параметр «Способ ввода»: камера, сканер,
фотографии, буфер обмена или ввод текста. Те же действия доступны в Пункте управления,
на экране блокировки, в Spotlight и через Siri («Решить задание в AI Homework»).

Как это устроено: `Shared/QuickActionIntent.swift` — интент с `openAppWhenRun`, общий для
приложения и расширения `AIHomeworkControls`. При нажатии система открывает приложение и
выполняет интент в его процессе; `AppModel.perform(_:)` закрывает открытые окна и сразу
запускает камеру (или выбранный способ).

## Локальные языковые модели

Математика, физика, химия и информатика решаются **без модели**. Модель нужна только для
развёрнутых текстовых ответов.

### Apple Intelligence (рекомендуется)

Ничего устанавливать не нужно: на iOS 26 и устройствах с Apple Intelligence (iPhone 15 Pro и
новее) приложение использует системную модель через фреймворк Foundation Models. Статус модели
и причина недоступности показываются в **Настройки → Локальные модели**. Если системная модель
не поддерживает язык задания, приложение сообщит об этом, а не выдумает ответ.

### Своя модель Core ML

**Настройки → Локальные модели → Установить модель Core ML** → выберите в «Файлах» папку с:

| Файл | Назначение |
|---|---|
| `model.mlpackage` (или `.mlmodel` / `.mlmodelc`) | языковая модель: вход `input_ids` (Int32, `[1, N]`, необязательно `attention_mask`), выход `logits` (`[1, N, V]` или `[1, V]`) |
| `tokenizer.json` | байтовый BPE-токенизатор в формате Hugging Face (GPT-2, Qwen, Llama 3 и др.) |
| `manifest.json` (необязательно) | `{"name": "…", "promptTemplate": "{system}\n\n{prompt}\n\n", "stopTokens": ["<|im_end|>"], "contextLength": 1024, "temperature": 0.3}` |

Пример конвертации небольшой модели (на Mac, Python):

```python
import torch, coremltools as ct
from transformers import AutoModelForCausalLM, AutoTokenizer

name = "Qwen/Qwen2.5-0.5B-Instruct"
model = AutoModelForCausalLM.from_pretrained(name, torch_dtype=torch.float32).eval()

class Wrapper(torch.nn.Module):
    def __init__(self, m): super().__init__(); self.m = m
    def forward(self, input_ids): return self.m(input_ids=input_ids, use_cache=False).logits

example = torch.zeros((1, 16), dtype=torch.int32)
traced = torch.jit.trace(Wrapper(model), example)
mlmodel = ct.convert(
    traced,
    inputs=[ct.TensorType(name="input_ids", shape=(1, ct.RangeDim(1, 1024)), dtype=int)],
    outputs=[ct.TensorType(name="logits")],
    minimum_deployment_target=ct.target.iOS17,
    compute_precision=ct.precision.FLOAT16,
)
mlmodel.save("model.mlpackage")
AutoTokenizer.from_pretrained(name).save_pretrained(".")   # даёт tokenizer.json
```

Для Qwen-моделей добавьте `manifest.json` с шаблоном чата:
`"promptTemplate": "<|im_start|>system\n{system}<|im_end|>\n<|im_start|>user\n{prompt}<|im_end|>\n<|im_start|>assistant\n"`.

Модель запускается без KV-кэша (каждый токен — полный прогон), поэтому выбирайте модели до
~1B параметров. Чтобы подключить другой рантайм (например, MLX или llama.cpp), реализуйте
протокол `LanguageModelProvider` и добавьте провайдер в `SolveCoordinator.providers()`.

### Классификатор предметов (необязательно)

Классификатор текста Create ML с метками `math`, `physics`, `chemistry`, `russian`, `english`,
`history`, `social`, `biology`, `geography`, `literature`, `informatics` устанавливается тем же
способом и уточняет автоматическое определение предмета.

## Архитектура

```
AIHomework/
├── App/            точка входа, AppModel (навигация, источники ввода, быстрые действия), настройки
├── DesignSystem/   стекло, кнопки, фон, орб, общие компоненты
├── Features/       Home, Capture, Solve (MVVM: SolveViewModel + экраны), History, Subjects, Settings
├── Services/       OCR (Vision), анализ текста, модели (Apple Intelligence, Core ML), PDF, координатор
├── Persistence/    SwiftData-модель истории
└── Engine/         движок решения без UI: Math, Physics, Chemistry, Text, Core
Shared/             App Intent «Решить задание» (приложение + расширение)
AIHomeworkControls/ элементы управления iOS 18 для Пункта управления и кнопки действия
EngineTests/        тесты движка
```

Движок (`AIHomework/Engine`) не зависит от UIKit и собирается отдельно как Swift-пакет,
поэтому его можно тестировать даже на Linux:

```bash
cd ai-homework-ios
swift test        # 38 тестов: математика, физика, химия, информатика, предметы, модели
```

CI (`.github/workflows/ai-homework-ios.yml`) прогоняет тесты движка и собирает установочный
файл `AIHomework.ipa` для iPhone на облачном macOS-раннере.

## Ограничения

* Физика — задачи в одно действие; многошаговые задачи требуют языковой модели.
* Рукописный текст Vision распознаёт хуже печатного — проверяйте распознанное условие (его можно исправить перед решением).
* Задачи на геометрию с чертежами не распознаются как чертежи — только текст условия.
* Ответы языковых моделей помечаются как сгенерированные и могут содержать ошибки.
