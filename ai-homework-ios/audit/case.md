# Материалы дела: аудит AI Homework

Проект: `/home/user/claude-code-best-practice/ai-homework-ios` (только эта папка; остальной репозиторий не относится к делу).

## Что это
iOS-приложение «решатель домашних заданий» в стиле Circle to Search: скриншот или фото → обвести область →
распознавание текста (Apple Vision) → решение → история, PDF, «Поделиться». Swift 6, SwiftUI, iOS 17+,
SwiftData, App Intents (кнопка действия, Пункт управления), RU/EN. Ставится сайдлоадом через SideStore
(Mac у владельца нет; .ipa собирает GitHub Actions на macOS, неподписанная сборка).

## Как устроено решение (по коду, не проверено на устройстве)
- `AIHomework/Engine/**` — «движок»: точные алгоритмы (математика, физика, химия, информатика),
  определение предмета, промпты, формат запросов к API, маршрутизация, лимиты времени.
  Собирается отдельным SwiftPM-пакетом (`Package.swift`, тесты `EngineTests/`) и тестируется на Linux.
- `AIHomework/Services/SolveCoordinator.swift` — порядок: если настроен API пользователя, нейросеть-«диспетчер»
  (`Engine/Core/TaskRouting.swift`) решает, отдать задание точному решателю (переписав условие) или решить по API;
  без API/интернета — точный решатель → Apple Intelligence (FoundationModels, iOS 26) → честный отказ.
- API: формат OpenAI или Anthropic, адрес/модель/ключ задаёт пользователь (сейчас — агрегатор apimira),
  ключ в Связке ключей. В API уходит текст и **выделенный фрагмент изображения (JPEG)**.
- Core ML-модели раньше были, но по решению владельца удалены (заменены нейросетью по API).
- Дизайн недавно переделан по дизайн-системе Linear (монохром + один акцент `#5e6ad2`, плоские поверхности,
  тонкие рамки, спокойные пружины). Имена `glassCard`/`GlassButton` остались от прошлого «стеклянного» дизайна.

- `swift test` движка в Docker `swift:6.2` на Linux: **57 тестов, 0 падений** (запуск этой сессии).
- GitHub Actions на `macos-15` собирает неподписанный архив Xcode без ошибок (последняя сборка 1.0.15 — успешна).
  Это значит: проект компилируется. Предупреждения компилятора не анализировались.
- **Не проверено**: запуск на устройстве или симуляторе, UI-тесты (их нет), поведение камеры/разрешений,
  реальная работа Vision OCR, Apple Intelligence, производительность, память. Владелец пользуется приложением
  на iPhone и сообщал о проблемах: OCR читал x как ×, «сетевое соединение потеряно», «бесконечно решает»
  (после этого добавлены повторы, лимиты времени и диспетчер).
